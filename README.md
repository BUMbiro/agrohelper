## 🌾 АгроХелпер – помощь фермерам и агробизнесу

**АгроХелпер** – это учебный веб-сайт, созданный для продвижения двух услуг:
- **Оформление деклараций о соответствии** для фермеров (ИП и КФХ).
- **Обучение по безопасному обращению с пестицидами и агрохимикатами** (в рамках Россельхозцентра).

Проект реализован на чистом Python без фреймворков, с использованием встроенного модуля `http.server` и 
Bootstrap 5 для вёрстки.

---

## 🎯 Что умеет этот сайт?

- Отдавать HTML-страницы с помощью `http.server`.
- Рендерить шаблоны с поддержкой наследования (`{% extends %}`) и блоков (`{% block %}`).
- Обрабатывать GET-запросы и показывать страницы: главная, декларирование, обучение, база знаний, блог, контакты.
- Принимать POST-запросы из форм и выводить данные в консоль сервера.
- Отдавать статику (CSS, изображения).
- Показывать кастомные страницы 404 и 500.

## 🛠 Установка и запуск

**Клонируй репозиторий**
```bash
git clone https://github.com/твой-логин/agrohelper.git
cd agrohelper
```
**Запусти сервер:**
```bash
python main.py
```
**Сервер будет доступен по адресу:**

```text
http://localhost:8000
```
**Чтобы остановить сервер — нажми `Ctrl+C`.**

## 🧭 Страницы

| Адрес | Что показывает |
|-------|----------------|
| `/` | Главная с двумя услугами, блок "О нас" |
| `/declaration` | Услуга "Декларирование продукции" + форма заказа |
| `/training` | Услуга "Обучение по пестицидам" + форма записи |
| `/knowledge` | База знаний (справочные материалы) |
| `/blog` | Блог / новости / FAQ |
| `/contacts` | Контакты, форма обратной связи, карта Астрахани |
| Любой другой адрес | Страница 404 |

## 🧪 Как проверить, что всё работает?

1. Запустите сервер → python main.py

2. Откройте главную → http://localhost:8000/ – баннер и карточки услуг.

3. Перейдите в «Декларирование» → заполните форму и отправьте – данные появятся в консоли.

4. Перейдите в «Обучение» → аналогично проверьте форму.

5. Перейдите в «Контакты» → проверьте форму и карту.

6. Попробуйте несуществующий адрес → должна открыться 404.

## 📝 Обработка POST-запросов
Все формы на сайте (/declaration, /training, /contacts) отправляют данные методом POST. На сервере они принимаются, 
выводятся в консоль и возвращают редирект на ту же страницу.

Пример вывода в консоли:

```text
========================================
📩 Получен POST-запрос на /declaration:
  product: Пшеница
  variety: Сорт1
  year: 2024
  scheme: 1Д
  object_type: серийный
========================================
```
