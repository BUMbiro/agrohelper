## 🚀 AstroWeb — космическое веб-приложение на чистом Python

**AstroWeb** — это учебный проект, в котором я на практике разбираюсь с тем, как работает веб «под капотом». 
Без фреймворков, только стандартная библиотека Python и Bootstrap для красоты. 
Здесь нет сложного бэкенда или базы данных — только сервер, маршруты, шаблоны и космическая атмосфера.

---

## 🌌 Что умеет этот проект?

- **Отдавать HTML-страницы** с помощью встроенного модуля `http.server`.
- **Рендерить шаблоны** с поддержкой наследования (`{% extends %}`) и блоков (`{% block %}`) — 
как в настоящем фреймворке.
- **Обрабатывать GET-запросы** и показывать страницы: главная, услуги, контакты, о нас.
- **Принимать POST-запросы** из формы обратной связи и выводить данные в консоль сервера.
- **Отдавать статику** (CSS, изображения) через отдельный обработчик.
- **Показывать кастомные страницы 404 и 500** — чтобы пользователь не терялся в космосе.
- **Использовать Bootstrap 5** для адаптивной вёрстки и кастомные стили с космической тематикой.

## 🛸 Запуск

**Клонируй репозиторий**
```bash
git clone https://github.com/твой-логин/astroweb.git
cd astroweb
```
**Запусти сервер:**
```bash
python main.py
```
**Сервер будет доступен по адресу:**

```text
http://localhost:8000
```
**Чтобы остановить сервер — нажми `Ctrl+C`.**

## 🎨 Космический дизайн
- Тёмный фон с мерцающими звёздами (через `CSS`-градиенты).

- Неоново-голубые акценты `(#7ec8e3)`.

- Стеклянные карточки `(backdrop-filter: blur())`.

- Анимации при наведении.

- Иконки из `Bootstrap Icons` (ракета, звёзды, глобус).

## 🧪 Как проверить, что всё работает?
1. **Запусти сервер** → `python main.py`

2. **Открой главную** → http://localhost:8000/ — видишь баннер и иконки?

3. **Перейди в «Контакты»** → заполни форму и отправь.

4. **Посмотри в терминал** — должны появиться данные из формы.

5. **Попробуй несуществующий адрес** → должна открыться `404`.

6. **Проверь, что `CSS` загружается** — страницы должны быть тёмными, с неоновыми акцентами.
